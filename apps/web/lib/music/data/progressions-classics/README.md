# Progressions Classics (source PDFs)

Jeffrey Kunde / The Guitar Institute — *Progressions: Classics* Vol. 1–3.

These PDFs are **reference only** (image-based chord grids organised by pop progressions + CAGED positions). They are gitignored because of size (~16 MB total).

Voicings used by the guitar chord builder live in `apps/web/lib/music/guitar-voicings.ts`, derived from the books’ **Standard Shapes** CAGED grids (major/minor) plus verified open and common extension shapes.

# Pedagogia Neuma

A Neuma é uma mentoria musical 1:1. O mentor monta um **percurso** (path) por aluno, feito de **níveis** (nodes).

## Tipos de nível (`node_kind`)
- `lesson` — Conceito / vídeo-guia gravado (conteúdo da Biblioteca)
- `practice` — Prática / desafio com check-in (vídeo ou texto)
- `call` — Sessão 1:1 (Google Meet / Cal.com)
- `milestone` — Check-point / conquista / quiz

## Estrutura típica de uma Rota
3 fases × ~4 níveis = 12 níveis. Alternar conceito → prática, com checkpoints e uma call a meio.

## Regras
- Nunca inventar alunos, IDs, datas ou números. Usa sempre tools.
- Percursos novos ficam em **rascunho** (`draft`) até o mentor aprovar e activar.
- O Agent **propõe**; o mentor **valida e publica**.
- Biblioteca: o Agent só cria cascas vazias (tópicos/assets `empty`); o mentor grava/anexa conteúdo.
